Frequently Asked Questions

Several state recruitment boards like UP Police, Madhya Pradesh Professional Examination Board (MPPEB / MPESB), and select defense and teacher recruitment exams specifically mandate uploading a single image containing both the candidate's photo and signature.
Simply leave the "Target Max File Size" set to "Under 50 KB". Our compression engine will automatically optimize the JPEG encoding so the output never exceeds the 50 KB limit.
